Phase 7 component · final stage of two-stage scheduler.

> Owner: TBD / 2026-05

> 版本: V2.1.0-alpha
> 设计依据: [[Phase-7-多智能体与行业理解]] § 双阶段调度 + 决策记录 Phase 7 runtime locked = OpenAI Agents SDK

## 职责

把 `MultiAgentSpec` 编译为可部署的 Python 代码（OpenAI Agents SDK 风格）。

```
NL --(IndustryRouter)--> Classification
                             |
                       is_multi_agent=True
                             ↓
              (IndustryDesigner) --> MultiAgentSpec
                                            ↓
                          (MultiAgentComposer this) --> Python source string
                                            ↓
                                      [部署 Gate] zip + 凭据清单
```

## 接口

```python
class MultiAgentComposer(Protocol):
    def compile(self, spec: MultiAgentSpec) -> str: ...
```

## V2.1.0 实现

`OpenAIAgentsSDKComposerImpl` (`impl.py`)：

- **纯模板，无 LLM**：保证确定性（同 spec 同输出）
- **AST 自检**：emit 后用 `ast.parse()` 校验，模板 bug 立即 RuntimeError
- **两遍 Agent 声明**：先声明所有 Agent（handoffs=[]）→ 再用 `agent.handoffs = [...]` 二次赋值，避免前置引用
- **变量名 sanitize**：`_agent_var()` 把 specialist id 转为 snake_case + `_agent` 后缀，处理首位数字、非法字符
- **字符串安全转义**：`_py_str()` 处理双引号、反斜杠、换行
- **结构守门**：`validate_graph()` 不通过时 ValueError
- **Runtime 锁**：`spec.runtime != "openai_agents_sdk"` ValueError

## 输出代码结构

```python
# AUTO-GENERATED by agent-ops MultiAgentComposer
from agents import Agent

# ---- Specialists (handoffs=[] 首遍) ----
flight_info_agent = Agent(name=..., handoffs=[], ...)
booking_agent     = Agent(name=..., handoffs=[], ...)
...

# ---- Triage (entry) ----
triage_agent = Agent(name=..., handoffs=[flight_info_agent, ...], ...)

# ---- Handoff wiring 二次赋值 ----
flight_info_agent.handoffs = [booking_agent, faq_agent]
faq_agent.handoffs = [refunds_agent]

# ---- 元数据导出 ----
HANDOFF_RULES: list[dict] = [{"from": "...", "to": "...", "when": "..."}]
GUARDRAILS: list[dict] = [{"kind": "relevance", "description": "...", "blocking": True}]
SHARED_CONTEXT_FIELDS: list[dict] = [{"name": "...", "type": "...", ...}]

# ---- Public exports ----
ENTRY_AGENT = triage_agent
ALL_AGENTS = [triage_agent, flight_info_agent, ...]
SPECIALIST_AGENTS = [flight_info_agent, ...]
```

## 不做的

- **不调 LLM**：编译期完全确定，所有不确定性留给 Designer 阶段
- **不绑定具体 prompt 文本**：emit `# TODO: bind prompt asset prompt.x.v1` 注释，部署层注入
- **不绑定具体 tool 函数**：emit `tools=[]` + `# TODO` 注释，部署层根据 atom_id 注入
- **不部署**：emit Python source string；写文件、起 venv、注入 secrets 是部署 Gate 的事

## 测试

`tests/test_composer.py` 14 个测试：
- `_agent_var` helper：常规 / 非法字符 / 首位数字
- `compile()` 出 AST 可 parse
- 5 个 specialist 全部 emit 为 ast.Assign
- 必要 export 全在（ENTRY_AGENT / ALL_AGENTS / HANDOFF_RULES / GUARDRAILS / SHARED_CONTEXT_FIELDS）
- 两遍 handoff wiring 正确
- HandoffEdge / Guardrail / SharedContext 元数据正确
- 幂等（同 spec 字节级一致）
- 拒绝 runtime != openai_agents_sdk
- 拒绝 validate_graph 不通过的 spec
- 极简 spec（无 handoffs / 无 guardrails / 无 shared context）输出合法 Python
- 字符串中的双引号正确转义

## 集成点

```
spec = await GeneralDesigner().design_multi_agent(nl, classification)
src = OpenAIAgentsSDKComposerImpl().compile(spec)
# src 是完整 Python 模块字符串，可直接写到 agents/__generated__/{system_id}/main.py
```
